ZENITH

zero-touch engine for incident threat handling · replay mode

An autonomous SRE agent that forecasts incidents before they breach, diagnoses root cause via LLM reasoning grounded in a runbook knowledge base (Groq / Llama 3.3 70B — falls back to a deterministic offline classifier if no key is set), writes a fix, security-audits its own patch, sandbox-verifies it, then deploys — with no human in the loop. Every step is hash-chained for tamper-evidence.
